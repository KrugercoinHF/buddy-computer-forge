# Score rubric

node skill.js score is a presence heuristic, not an AI quality score or readiness certification.

- Each required foundation file present: 1 point.
- Missing file: 0 points.
- Percentage = points / checks × 100.

It does not measure correctness, security, runtime behavior, provider quality, user value, production readiness or evidence of execution. Use node skill.js verify for JSON/ledger checks and owner-run tests for promotion.
